# AbsenceSoft

> AbsenceSoft is a leave and accommodations management SaaS platform that automates the administration of employee absences and workplace accommodations, with a compliance engine covering 200+ federal, state, and territorial leave laws (FMLA, ADA, PWFA). It exposes an API-first REST API — the same APIs that power the AbsenceTracker application — with OAuth2 authorization, webhooks, and file-based batch integration.

## APIs
- [AbsenceSoft REST API developer portal](https://absencesoft.stoplight.io/docs/api-specs/46b38f624d360-welcome-to-the-absence-soft-api): OpenAPI 3.1, OAuth2 (password + client credentials), employee data, leave and accommodations cases, employer configuration, communications.
- [API overview](https://absencesoft.com/apis/): system-agnostic open REST API for enterprise integrations.
